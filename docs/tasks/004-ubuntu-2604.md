## Goal

A fresh 26.04 (resolute) box installs the whole Obcell, **installing itself** (bootstrap.sh +
ansible-core 2.20 on Python 3.14), with the same results as 22.04.

## Context

- See [docs/ubuntu-releases.md](../ubuntu-releases.md) for the 2026-11-21 checks.
- **MongoDB** doesn't publish a server for resolute yet (only the client tools).
  `mongodb_repo_release` falls back to the noble 8.0 repo; a dry-run install there resolved
  every dependency. It has not been started yet. MongoDB needs AVX on x86, which the test
  machine's CPU must have.
- **Toolchain jumps from 22.04:** gcc 11→15, cmake 3.22→**4.2**, mbedTLS 2.28→**3.6**,
  Boost 1.74→1.90, Python 3.10→3.14. Likely failures:
  - CMake 4 refuses `cmake_minimum_required(VERSION <3.5)` in srsRAN_4G or bundled
    sub-projects. Fix: add `-DCMAKE_POLICY_VERSION_MINIMUM=3.5` to the cmake args
    (`ocudu_cmake_args`, and the srsUE build).
  - srsRAN_4G 23.11 against mbedTLS 3: may need a patch, or building srsUE may need to
    become optional on 26.04 (it is only the virtual test phone).
  - gcc 15 errors (missing `<cstdint>` and similar) in the pinned sources: small patches.
- **Controller:** `passlib` is unmaintained. Check that the Authelia argon2id and Strom
  bcrypt hashing in `tasks/secrets.yml` still works on Python 3.14. If it doesn't, call
  `argon2-cffi` and `bcrypt` directly.
- A 26.04 container may already exist from an aborted attempt (`obcell-resolute`, which
  also has a hand-added MongoDB list file); use `--fresh`.

## Steps

1. `tests/matrix.sh --fresh 26.04` (inside controller is the default, which is the point
   here).
2. Fix failures as in task 003: release-neutral fixes first, per-release variables where
   needed, patches in `files/patches/`.
3. Also run `--controller outside` once, to see whether ansible-core 2.17 (Python 3.10
   controller) can drive a Python 3.14 target. If it can't, document that 26.04 Obcells need a
   newer controller.
4. Re-check 22.04 and 24.04 for regressions.
5. Update the docs.

## Done when

- [ ] `tests/matrix.sh --fresh 26.04`: install, health, idempotent and NG Setup are PASS.
- [ ] MongoDB from the noble repo runs and verify sees the subscriber.
- [ ] 22.04 and 24.04 still pass.
- [ ] The docs say 26.04 is tested, or list exactly what's missing.
