## Goal

A fresh 24.04 (noble) box installs the whole Obcell with the same results as 22.04, so a new
Obcell can be built on 24.04.

## Context

- Package availability was checked on 2026-11-21 (see
  [docs/ubuntu-releases.md](../ubuntu-releases.md)). Everything is in the archive or the
  third-party repos. LimeSuite 23.11 comes from the Ubuntu archive, and MongoDB 8.0 from
  its noble repo.
- What has never been tried:
  - building the pinned OCUDU (`077b0808ab`) with gcc 13 / cmake 3.28 / Boost 1.83;
  - building srsRAN_4G `release_23_11` with gcc 13;
  - the Open5GS WebUI npm build on Node 20 there;
  - running the playbook with ansible-core 2.20 (the inside controller picks it on
    Python 3.12). ansible-core 2.19+ templating is stricter: look for errors about
    conditionals that aren't booleans, `when:` with `{{ }}`, and undefined variables in
    lazy templates.
- MongoDB 8.0 on a new box is fine; there is no old data to migrate.
- A 24.04 container may already exist from an aborted attempt (`obcell-noble`); use
  `--fresh` to start clean.

## Steps

1. `tests/matrix.sh --fresh 24.04`
2. Fix failures one at a time. Prefer release-neutral fixes; where something really
   differs per release, add a variable (as with `mongodb_repo_release`).
   - Source build failures: try a compiler flag or a small patch in the role's
     `files/patches/` (applied by `roles/common/tasks/git_patched.yml`). Bump a pin only if
     it is low-risk, and note it.
   - ansible-core 2.20 issues: fix them so the playbook still works on 2.17 too (CI runs
     both).
3. After each fix, re-run `--only install,idempotent,radio 24.04` (the container keeps the
   finished builds).
4. Check that 22.04 didn't regress: `tests/matrix.sh 22.04` (it reuses its container).
5. Update `docs/ubuntu-releases.md` and the README table: 24.04 **Tested**.

## Done when

- [ ] `tests/matrix.sh --fresh 24.04`: install, health, idempotent and NG Setup are PASS
      (UE end-to-end PASS, or tracked in task 005).
- [ ] 22.04 still passes.
- [ ] The docs say 24.04 is tested, with the date and commit.
